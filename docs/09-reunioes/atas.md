# Atas das reuniões de orientação

Este documento reúne os registros das reuniões realizadas com o orientador durante o desenvolvimento do Trabalho de Graduação.

As atas têm como objetivo documentar os assuntos discutidos, as orientações recebidas, as decisões tomadas e as atividades definidas em cada encontro, mantendo um histórico do acompanhamento e da evolução do projeto.

Os registros serão organizados cronologicamente e atualizados após cada reunião.
