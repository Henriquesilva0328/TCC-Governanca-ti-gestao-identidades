# Roteiro de entrevista — Estudantes

## Objetivo

Compreender a experiência dos estudantes durante a utilização dos laboratórios e identificar dificuldades que possam não aparecer nos registros técnicos.

## Perguntas

1. Como você normalmente acessa os computadores dos laboratórios?

2. Você já encontrou alguma dificuldade ou problema durante esse processo? Qual?

3. Você já encontrou arquivos, configurações ou informações deixadas por outro usuário no computador?

4. Você já precisou trocar de computador ou solicitar ajuda devido a algum problema de acesso?

5. Como você avaliaria a utilização de uma conta individual para acessar os computadores, semelhante às contas utilizadas em outros serviços institucionais?

6. O que poderia tornar um login individual inconveniente ou atrapalhar sua utilização dos laboratórios?

## Privacidade

Não solicitar:

- RA;
- CPF;
- senha;
- credenciais institucionais.

As respostas deverão ser utilizadas para compreender a experiência geral dos estudantes, sem necessidade de identificação individual.
